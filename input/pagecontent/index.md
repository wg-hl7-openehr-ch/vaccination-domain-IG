### Introduction
The CH Vaccination Domain Service implementation guide describes the architecture of the Vaccination Domain Service and defines the openEHR archetypes and also the FHIR to openEHR mappings.
This implementation guide is dependent on the CH VACD Implementation Guide [CH VACD](http://fhir.ch/ig/ch-vacd/index.html) which describes the vaccination exchange formats.


### Collaboration
This implementation guide is under the guidance of the joint working group of [HL7 Switzerland](https://www.hl7.ch) and [openEHR Switzerland](https://www.openehr.ch)
